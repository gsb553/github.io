Production Diary – Week 5

Date: 10 February 2026

This week I continued developing my GitHub Pages portfolio website. I focused on organising the main sections of my homepage, including About, Skills, and Contact, and making sure the structure was clear and easy to navigate.

I am most proud of successfully publishing my website and seeing it live online. It was satisfying to understand how the different HTML elements work together to form a complete webpage.

I found it challenging to make sure my HTML structure was correct, especially remembering to close tags properly and keep the layout organised. Small mistakes caused errors, which showed me how important attention to detail is in web development.

Through this process, I improved my understanding of semantic HTML, page structure, and basic CSS styling. I also learned more about how GitHub Pages deploys a website from a repository.

Next week, I would like to improve the visual design of my site and begin adding a project section so I can showcase practical programming work.
